# Rights register

Where everything in Snowed In comes from. Everything is original to this
project unless listed.

| Thing | Source | Notes |
| --- | --- | --- |
| Name, setting, story, characters, monsters | Original | Pinehollow, the Great Hearth, Frostlings, Snow Hounds, Snow Brutes, Ice Wisps, the Old Yeti and Elder Yeti. Yetis are folklore, not anyone's design |
| Code | Original | Some patterns (rate limiter, session lock, receipt ledger, pass service) adapted from Halloween Tycoon in this repo |
| 3D models | Original | Built from parts in code (`src/shared/World/`); no Toolbox or marketplace models |
| Sounds and music | Original | Synthesised by `tools/make_sounds.py`; "Hearthside", "Long Night" and "Yeti Stomp" are original tunes |
| Fallback sounds | Roblox | `rbxasset://sounds/...` files that ship with Roblox, only used until the uploads are in |
| Fonts and particle textures | Roblox | Built-in fonts (Fredoka One, Gotham) and `rbxasset://textures/particles/...` |
| Pass icons | Original | Rendered offline from the game's own models with three.js (MIT licence); three.js is not part of the game |
| Store icon and thumbnails | To be made | From the prompts in `docs/marketing.md` with an AI image tool; check its terms allow commercial use, and don't prompt for any real game, brand or character |

The genre (survive a set number of nights, gather by day, defend at night) is
common to many games and isn't owned by anyone; nothing here copies another
game's names, characters, art, sounds or maps.
